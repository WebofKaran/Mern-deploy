# MERN Deploy Lab

An interactive MERN Stack learning project demonstrating MongoDB, Express, React, Node.js, Docker, and Jenkins.

## Project structure

- `client/` — React frontend
- `server/` — Express API
- `docker-compose.yml` — Container orchestration
- `Jenkinsfile` — CI/CD pipeline

## Run locally

```bash
docker compose up --build
```

Frontend: `http://localhost:5173`
API: `http://localhost:5000`
